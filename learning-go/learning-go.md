# Learning Go
Coming from dotnet, and having worked through a few Udemy courses, I figured that grabbing a book to work through the syntax and some of the basic workings of go would be helpful

Learning Go has many great reviews, has released its second edition within the last few years, using go 1.22 or so, and seems to be well written as I skimmed the index and a few pages
